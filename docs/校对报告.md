# EnglishPod 365 校对与播放器改造

本次将英文句子、中文参考译文、音频时间和场景范围集中到每课的 `lessons/englishpod_NNNN.json`。页面的 SRT 与 TXT 两个视图使用同一组句子；磁盘上的 SRT/TXT 由这一组句子导出，避免分别修改后产生差异。

## 校对方法

- 以修改前的 SRT/TXT 快照为底稿，逐课运行本地语音识别取得词级时间，检查原文匹配程度、顺序、音频长度及场景边界。基础检查使用 Whisper base.en；疑难片段使用 small.en、medium.en 复核。个别课程直接使用 small.en。
- 用课程场景原稿和可取得的主持人讲稿交叉核对。识别结果只作为证据，不整体覆盖原文；拼写差异、正常口头语和教学重复不会一律删除。
- 修正有证据的漏句、幻觉重复及词义错误；只有找到音频词边界时才拆开长段落，不按文字长度均分时间。不能可靠拆开的连续话语仍作为一个播放段落。
- 每课选取一次完整场景表演。若第一遍字幕缺损严重，可选后面一遍；讲解、示例句和其他重复表演保留在全文中。
- 中文译文按课程场景、角色关系、上下文和词汇讲解逐条审校；对短语动词、语气词、习语、术语和同形多义表达按所在课程分别处理，不使用单一英文键强行套用所有语境。所有译文随课程 JSON 提供，浏览器播放时不调用翻译服务。

这是音频识别与参考稿交叉校对，不等同于人工逐小时试听认证。噪声、角色表演、歌唱、双关和口语仍可能有理解误差。

## 第 156 课的音源修正

原 `EnglishPod/assets/englishpod_F0156pb.mp3` 实际是约 272 秒的纯场景版本，播放器的字幕则对应约 1017 秒的完整课程。这会让字幕、讲解和播放位置整体错位。已从同一课程资料集补入完整 PB 音频，放到播放器的第 156 课路径；原始目录文件保留，播放器原短版本另有备份。

尖叫表演中的部分台词无法被多种识别模型可靠辨清。该段参照课程原稿恢复为一个连续交流段，保留“段落点击”和整段循环，不捏造每句独立时间。这段须与普通清晰对白的逐句对齐区别看待。

## 特殊内容

- 第 66 课包含 Pig Latin：按课程原稿恢复词形，并给出对应中文含义。
- 第 132 课汽车故障对白中的 `spewing white smoke`：课程原稿与主持人的词汇讲解一致；语音识别误作 `being`，按语义和原稿更正。
- 第 179 课歌曲仅收录音频实际演唱的第一节，没有把原稿中未演唱的其他段落补进时间轴。
- 第 180 课补回原字幕漏掉的歌曲；Dialog 选择一次完整主歌加副歌，随后淡出的重复部分留在全文。
- 第 321 课实录与原稿均把青木瓜沙拉称作 `Tom Sam`；英文按实录保留，中文注明通常名称为 `Som Tam`。参考稿与音频冲突时，不盲目改成参考稿，例如第 339 课三次实录均称 `Mr. Weber`，没有照原稿改成 `Mrs. Webber`。
- 对话中的 “Yes.”、“Right.” 等短回应是有效话轮，不为了形成书面长句而强行并入其他人的话。

## 验证记录

- 365 课全部完成基础音频识别与 small.en 疑难片段复核，总音频约 80.966 小时；365 个在用音频的 SHA-256 与核验音源全部一致。
- 最终生成 95,948 个中英文文本片段，中文字段无空白；365 个 Dialog 共选取 8,317 个片段，并逐课检查所选场景中文。
- 有记录的英文/时间修正共 420 组，涉及 225 课；其中尾部专项修正 94 项。修正范围包括假重复、漏句、错误词形、场景首尾及固定一秒造成的错位。
- 365 组 SRT、TXT 与课程 JSON 的英文、句序和时间一致；无缺失音频、无越界句子、无时间重叠、无未解决的 Dialog 边界错误。
- 28 项 Python 数据处理测试、19 项播放器核心与浏览器交互测试通过。
- 发布到本地项目后，第 1、156、365 课使用真实 MP3 的浏览器验收通过：中文默认关闭、中文显示、Dialog 过滤、点击播放、单句循环、范围限制、SRT/TXT 一致性，浏览器无脚本错误。此前亦用第 30、132、145、150、179、180 课做过真实音频集成验证。
- 本项目是静态网页，未执行 Android armDebug 构建；未执行 Git 提交、SVN 写入或外部网站部署。

## 仍需区分的情况

- 先前记录的 28 处残句已逐项复查处理。25 处历史长段中，保留的两处是第 129 课同一句演讲长句的两次朗读，本身就是完整复合句；没有为缩短显示而破坏句意。
- 第 156 课的尖叫交流保留为整段，循环也按这一段进行；详见上文，不能视作每句都已精确分离。
- 第 75 课牙科场景的连续 `Ah` 可能包含治疗时的非语言声音，识别模型不能可靠辨词，保留原记录并在核验材料中标记，未假造新的对白或精确声源边界。
- 全文讲解和 Dialog 译文均属于学习参考译文；本轮根据已有场景审校记录回填了 169 条上下文修订，覆盖 104 课。仍可能存在需要结合音频语气进一步调整的句子，这不构成零误译或逐小时人工试听保证。
