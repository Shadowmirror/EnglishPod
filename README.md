# EnglishPodPlayer

面向 EnglishPod 365 课的浏览器学习播放器，支持中英对照、逐句播放、场景对话练习和置顶桌面字幕。页面直接读取静态课程数据，无需账号或数据库。

## 快速开始

1. 准备 Python 3（本项目使用 Python 3.11 验证）。
2. 获取本仓库，保留 `mp3/`、`lessons/`、`srt/`、`txt/`、`md/` 和 `manifest.json` 的目录结构。365 课音频及文本随仓库提供，音频合计约 2.35 GB。
3. 在项目目录执行：

```bash
python serve.py 8848
```

Windows 也可使用 `py -3.11 serve.py 8848`。打开 [本机播放器](http://127.0.0.1:8848/)，按 `Ctrl+C` 停止服务。

`serve.py` 仅监听本机，已支持音频跳转所需的 HTTP Range 请求。不要直接双击 HTML 以 `file://` 打开，也不要用 `python -m http.server` 替代此服务。

音频、字幕、全文和知识讲解均纳入版本管理。正常播放需要课程 JSON、音频和索引；知识讲解读取已有 Markdown，不要求同时提供 PDF。知识讲解的 Markdown 渲染库目前从 jsDelivr 加载，完全离线使用前需改为本地资源。

## 学习与播放

| 功能 | 行为 |
| --- | --- |
| SRT 字幕 / TXT 全文 | 共用课程 JSON 中的句子、译文和时间轴，同步高亮与滚动 |
| 中文翻译 | 默认关闭，可随时切换；译文按课程场景和上下文审校 |
| 完整节目 / 对话 | 完整节目保留讲解；对话模式仅显示并播放一次选定的场景表演 |
| 切换播放内容 | 跳到目标模式的首句，保持当前播放或暂停状态 |
| 点击句子 | 跳到该句并开始播放；支持 Tab 定位和 Enter/空格操作 |
| 单句循环 | 循环所选句子，点击另一句更换目标；优先于课程循环 |
| 顺序播放 | 当前课程或对话结束后进入下一课，末课结束后停止 |
| 单曲循环 | 重复当前课程或当前课程的对话片段 |
| 列表循环 | 顺序播放全部课程，末课结束后返回第一课 |
| 空白间隔保留高亮 | 默认开启，两句间保留前一句高亮，不改变音频时间 |
| 倍速 | 桌面字幕提供 0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×，与主页面音频控件同步 |
| 知识讲解 | 展示课程场景稿、重点词汇与补充词汇 |

## 桌面字幕

点击“桌面字幕”打开置顶小窗，与主页面共用音频。小窗可切换课程、上一句/下一句、播放/暂停、课程循环、单句循环、完整节目/对话、中文和倍速。关闭小窗后音频继续播放；关闭或刷新主页面会关闭小窗。

### 界面与布局

- 标题、图标操作栏和设置面板悬浮在字幕上方，不占字幕高度，也没有整条背景蒙版。操作栏可收起，通过右上角悬浮按钮恢复。
- 字号与间距根据窗口自动适配，多行使用统一字号。支持左对齐、居中、右对齐，以及背景色、字体色和恢复默认配色。
- 选择 1、2 或 3 行，并通过“横向滚动”决定长句的显示方式：

| 设置 | 长句行为 |
| --- | --- |
| 开启横向滚动（默认） | 每句保持单行；超长文字随该句音频进度从句首移动到句尾，暂停、跳转和循环时同步 |
| 关闭横向滚动，1 行 | 自动缩小当前句字号，完整显示在一行内 |
| 关闭横向滚动，2/3 行 | 当前句自然换行，按实际占用行数分配空间；只有剩余行数足够时才显示后一句 |

例如选择 2 行、当前句恰好换成两行时，只显示当前句，读完再切到下一句。当前句超过设定行数时仍保留完整内容，可纵向滚动查看。

开启横向滚动时，相邻句子切换带有短暂的纵向滚动过渡；切换课程或模式直接定位，系统设置为减少动态效果时取消过渡。

### 浏览器要求

小窗需要桌面浏览器支持 `Document Picture-in-Picture`，并在安全上下文中打开。使用支持此功能的 Chrome/Edge，通过 `http://localhost` 或 `http://127.0.0.1` 对应的本机服务地址访问即可。

浏览器管理窗口外框和最大尺寸，网页无法强制拉到全屏幕宽度；当前方案不支持透出桌面的透明背景或鼠标穿透，可通过配色调整显示效果。系统休眠或浏览器冻结仍可能影响播放。

## 本地记忆

设置保存在每位使用者自己浏览器的 `localStorage`，不上传服务器。

| 类型 | 保存内容 |
| --- | --- |
| 播放偏好 | 中文开关、空白高亮、完整节目/对话、单句循环开关、课程播放模式、倍速 |
| 课程 | 最近成功加载的课程编号 |
| 桌面字幕 | 行数、横向滚动开关、对齐、背景色、字体色、操作栏隐藏状态 |

刷新后恢复课程和偏好，不自动播放，不恢复音频秒数或上次单句循环目标。桌面字幕需要再次点击打开。不同设备、浏览器、协议、域名/IP 或端口分别保存设置；清除站点数据会重置这些记录。

## 数据维护与验证

`lessons/englishpod_NNNN.json` 是播放器句子数据的唯一来源。每句包含 `start`、`end`、`en`、`zh`；`dialog.segmentIds` 标识选定的一次场景表演，`dialog.start/end` 限定播放范围。时间单位为秒。

修改英文、分句或时间后，同步检查中文与 Dialog 范围，再导出 SRT/TXT。不要单独修改导出文件，否则会与页面数据不一致。

```bash
python tools/export_lessons.py
python tools/verify_dataset.py
```

验证脚本检查 365 课索引、音频文件存在性、句子数据合法性和 SRT/TXT 一致性，不等同于重新试听校对。仅导入音频时执行验证命令即可，无需重新导出或生成索引。

测试命令：

```bash
python -m unittest discover -s tests -p "test_*.py"
node --test tests/player-core.test.js
npm ci
npm test
```

Python 测试使用标准库。浏览器测试需要 Node.js 20 或更新版本和本机已安装的 Chrome；`npm ci` 安装 Playwright，`npm test` 运行核心及浏览器测试。可通过环境变量 `PLAYWRIGHT_CHANNEL=msedge` 改用已安装的 Edge。仅运行网页不需要安装 Node.js 或 Playwright。

课程资料参考 [EnglishPod 资料集](https://archive.org/details/englishpod_all)。音频识别、参考稿交叉校对和中文译文的处理方式及限制见[校对报告](docs/校对报告.md)。
